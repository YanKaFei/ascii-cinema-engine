# DRAFT-T2 — 结构面解构报告

## 做了什么

不再在墙上叠加一层粒子雾，而是**让墙本身的材质随碎裂被移除**。

`scripts/draftt-render2.mjs` 新增：

```js
function cellNoise(f, x, y)              // 确定性整数哈希，绝不用 Math.random
function deconstructProgressAt(f)        // 0 直到因果地标(frame 29)，跨碎裂升至 1，之后 120 帧衰减
const decon = deconstructProgressAt(f)   // 在 drawScene 内
```

`plane()` 改为**侵蚀填充、保留轮廓**。

### 为什么规则是「从边缘向内侵蚀」

`M.box` 迭代的是投影四边形的**轴对齐屏幕包围盒**，所以斜角时它覆盖到四边形**外面**的格子。
直接填内部会把墙的材质画到墙外。**包围盒只在自己的边界上是精确的**，所以从边缘向内侵蚀是
**唯一保证落在墙面上的区域**——而且「材质从边缘向内剥离」本身也是墙体失效更合理的读法。

外边界的判断是**拓扑性**的（`u`/`v` 在 0 或 1），所以**轮廓在解构中完全存活**：
面板从不失去它在空间中的位置，它失去的是**实质**。哈希噪声让退却**参差不齐**，而不是一个干净收缩的矩形。

### 确定性

整部引擎是逐字节验证的：同一份源码两次渲染必须得到同一部片子。
所以擦除图案来自 `(frame, x, y)` 的纯整数哈希——**同一帧、同一格、永远同一判决**。

## 我看到的画面，以及它的真实缺陷

帧 340：**墙体从边缘被啃出参差不齐的锯齿，内部留下镂空块，轮廓白色连线保留。**
红橙色碎片从四周向中心侵占。**视觉上确实读作「结构在失去实质」。**

**但我必须指出两处不足，它们不是细节：**

1. **中央核心完好。** 因为 `edge >= reach` 时直接返回基础值，每块面板的**中央从未被侵蚀**。
   结果是「墙被啃出锯齿 + 留下空心块」，读作**结构感下降**，而不是**「一间房间在解体」**。
   真正的解体应该是材质**整体**变薄、失去承载能力。

2. **侵蚀是逐面板的，不是空间性的。** `EDGE_BAND = 0.42` 在**屏幕空间**，
   所以每块墙、每根立柱、地板都从**自己的**边框开始侵蚀。
   而叙事上它是**沿接缝张开**的——几何上一致的做法应当是让侵蚀从**接缝**向外传播。

   **我选择了屏幕空间边界，是因为它在几何上可证明正确（包围盒只在边界处精确）。**
   那是一个可辩护的工程决定，但它**牺牲了叙事上的方向性**。

## 下一步（未执行，按优先级）

1. **侵蚀从接缝传播**，而不是从每块面板的屏幕边框。做法：在世界空间里计算到接缝的距离，
   只侵蚀接缝附近的面板材质。这需要放弃包围盒技巧、改为逐格点在四边形内测试。
2. **让中央也被侵蚀**：`reach` 足够大时（后期）应当吞掉整个面板宽度，
   使面板在碎裂末期**完全消失**，而不是留下核心。
3. **解构与碎裂材质 envelope 的协调**：目前 envelope 峰值（帧 350）与解构最深
   （帧 340–350）在争夺同一段画面，两者是否互相削弱未评审。

# 第二版：接缝驱动的侵蚀（修掉我自己指出的两个缺陷）

第一版的两个缺陷都已修复：

| 缺陷 | 修法 |
|---|---|
| **中央核心完好** | 删除 `edge >= reach` 短路。现在 `reach` 后期**超过 1.0**，面板会**真正消失**而不是留核心 |
| **逐面板而非空间性** | 每块面板声明 `seamUV`——**接缝在它自己参数空间中的位置**。一条规则覆盖后墙（接缝在中心）、侧墙与地板（接缝在深处）、立柱（接缝在竖向中心） |

**关键：没有做逐格投影。** 接缝位置以 UV 传入，所以投影开销不变。
`dist` 现在量的是**到接缝的距离**，不是到面板边框的距离。

## 实测对比

|---|---|---|---|

| 330 | 0.1786 | **0.1192** | **−0.0594** |

全片：平均 0.1111 → **0.1136**；sha256 `d77c6ad1ce0ca3e4`。

**帧 330 从 0.1786 降到 0.1192** —— 接缝处材质被真正移除，**中央路径打开了**。
帧 350 反而更高，因为碎裂材质的 envelope 在那里达到峰值，与解构深度在争夺同一段画面。

## 我看过的画面

帧 330：**墙体呈水平层理状降解；立柱变薄；接缝所在的中央出现一条真正打开的通路。**
这读作**空间在解体**，而不是第一版的「墙被啃出锯齿、留下空心块」。

## 确定性已验证

清理未使用的 `EDGE_BAND` 后，**两次独立渲染逐字节一致**（`d77c6ad1…`）。
擦除图案来自 `(frame, x, y)` 的纯整数哈希，所以解构是可复现的——这对整个引擎的
逐字节验证前提是必需的。
