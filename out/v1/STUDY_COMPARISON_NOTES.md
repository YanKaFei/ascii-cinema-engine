# V1 研究 vs 后续成片 — 实际观看与测量对比

**方法**：三份研究各自解码 90 帧，逐帧查看；墨覆盖在**解码后的实际像素**上按 4 像素栅格采样
（阈值 R+G+B > 90），不是读取渲染日志。

---

## 1. 三份研究分别是什么

| | 名称 | 实际内容 | 墨覆盖 (f1/f45/f89) | 字符/帧 |
|---|---|---|---|---|
| **A** | 动力字形雕塑 | **一个巨大的书法性字形**，笔画由数千字符密集堆叠而成，有起笔、收笔、粗细与字腔 | **0.125 / 0.082 / 0.175** | **38,537 / 27,878 / 36,156** |
| **B** | 电影化 ASCII 空间 | **线框建筑空间**：`+ - \| .` 勾出墙面与地板透视线，灭点在中景 | **0.035 / 0.036 / 0.035**（恒定） | ~3,400 |
| **C** | 字形场变形 | 稀薄字符场**凝聚成厚重方块字形**（"HATE"），底部有基线 | **0.001 / 0.041 / 0.067**（增长） | 84 → 4,567 → 7,017 |

### 关键核实：它们都是真正的网格 ASCII

`scripts/v1-studies.mjs` 里三者都用 `new M.Canvas({cols, rows})` + `cv.write(...)`，再经
`R.rasterise(cv.toLines(), ...)` 光栅化。**字符是逐格写入的，符合「完全 ASCII 字符构成」。**
（A 里出现的不同字号字符，是网格光栅化时字符字体本身的大小，不是逐字符矢量排版。）

## 2. 与后续成片的密度对比

| | f1 | f45 | 碎裂/后段 |
|---|---|---|---|
| A 雕塑 | 0.1250 | 0.0824 | 0.1753 |
| B 空间 | 0.0349 | 0.0355 | 0.0353 |
| C 字段 | 0.0009 | 0.0408 | 0.0668 |
| **DRAFT-T（新，无人）** | 0.0197 | 0.0198 | **0.0117** |
| R3.7.1（旧，有人） | 0.0197 | 0.0198 | 0.0128 |

**一个重要且不太舒服的发现**：
**DRAFT-T 的墨覆盖与 R3.7.1 几乎逐位相同（0.0197 / 0.0198）。**
也就是说 —— **去掉人形并没有改变影片的视觉密度。**
人形层确实消失了（441,533 格），但画面依然是同样稀疏、发灰的观感。

**DRAFT-T 是五者中最稀疏的**，而且它的碎裂时刻（F310，墨覆盖 0.0117）**是本片最暗的一帧之一**，
但那一帧在叙事上应该是高潮。

## 3. 诚实的优劣结论

### 比后续成片更好的地方

- **A 的材质密度**（每帧 3.8 万字符）远胜后续所有成片。观感是**雕塑**，不是「黑底上有些字」。
- **A 的可读性来自字形本身**：一个巨大字形，笔画的墨与纸由字符密度对比造出来，而不是靠加粗。
- **C 有真正的演化**：0.001 → 0.067，从几乎空白长成字形，这是**可见的转变**。
- **B 用最少的字符造出了可信的空间**：恒定 3,500 字符，透视线清楚，有纵深。

### 后续成片更好的地方

- **因果与身份**：后续有编译期验证的因果对（310/320）、85 个载体跨剪辑存活、可审计的 provenance。
  **V1 研究没有这些** —— 它们是「研究」，不是叙事片。
- **契约与回归**：518,975 条断言、双层回归、确定性重建（我实测重复渲染哈希一致）。
- **分层合成器**：深度、遮挡、遮罩都有实际计数。

### 后续成片更差的地方（这是重点）

1. **密度太低。** DRAFT-T 0.0197 vs A 的 0.125 —— **差 6 倍以上**。画面发灰、发空。
2. **碎裂时刻最暗，这几乎肯定是错的。** 高潮应当是视觉最强的时刻，不是最弱的。
3. **材质单一。** 后续只用了很少的字符家族；A 用 37 种不同字符，B 用 4 个家族分工（arch/detail/atmo/accent），
   C 有氛围→文字的转变。**后续的字符材质没有分工。**
4. **没有真正的「材质转变」。** C 从 atmosphere 变到 text，是**质料本身在变**。
   后续的表示变化（`SCENE_ASCII→TYPOGRAPHIC_GRAPHIC→GLYPH_FIELD`）机制存在，
   **但我这一轮没有把它接进 DRAFT-T**。

---

## 4. 我的判断

> **V1 的 A 和 C 比我后续做的任何一版都更接近你想做的那个东西。**
>
> 我这几轮把力气花在**工程正确性**（因果、身份、契约、可复现）上，这确实做厚了；
> 但**画面质感退步了** —— 从 3.8 万字符的雕塑，退到 0.0197 墨覆盖的稀疏线稿。

**后续该补的不是结构，是材质。** 具体三件事：

1. **把字符密度提上去**（至少向 B 的 0.035 看齐，冲刺时刻应向 A 靠），
   方法是让字符家族**分工**：结构用密集材质、边缘用方向字符、氛围用稀疏点。
2. **重排镜头的强弱**：碎裂时刻必须是全片视觉最强的一帧，而不是最暗的。
3. **把表示变化接进 DRAFT-T**：`SCENE_ASCII → TYPOGRAPHIC_GRAPHIC → GLYPH_FIELD` 是现成的，
   接上后才有 C 那种「质料本身在变」的效果。

**我没有修改任何东西** —— 这一轮只做了查看与测量。
